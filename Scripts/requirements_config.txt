# docker/Dockerfile
# Dockerfile for containerized deployment in UBS environment

FROM python:3.9-slim

# Set working directory
WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y \
    gcc \
    g++ \
    curl \
    && rm -rf /var/lib/apt/lists/*

# Copy requirements and install Python dependencies
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Download spaCy model
RUN python -m spacy download en_core_web_sm

# Copy application code
COPY . .

# Create non-root user for security
RUN useradd -m -u 1000 piiuser && chown -R piiuser:piiuser /app
USER piiuser

# Expose port
EXPOSE 8000

# Health check
HEALTHCHECK --interval=30s --timeout=30s --start-period=5s --retries=3 \
    CMD curl -f http://localhost:8000/health || exit 1

# Run the application
CMD ["python", "-m", "uvicorn", "api.main:app", "--host", "0.0.0.0", "--port", "8000"]

# deployment.md
# Deployment Guide for UBS Environment

## Prerequisites

1. **Python Environment**: Python 3.8+ required
2. **Memory Requirements**: Minimum 4GB RAM, recommended 8GB+
3. **Storage**: ~2GB for models and dependencies
4. **Network**: Offline deployment supported after initial model download

## Installation Steps

### 1. Environment Setup
```bash
# Create virtual environment
python -m venv pii_env
source pii_env/bin/activate  # Linux/Mac
# or
pii_env\Scripts\activate  # Windows

# Upgrade pip
pip install --upgrade pip
```

### 2. Install Dependencies
```bash
# Install from requirements.txt
pip install -r requirements.txt

# Download spaCy model
python -m spacy download en_core_web_sm
```

### 3. Model Download (One-time)
```bash
# Download transformer models for offline use
python -c "
from transformers import AutoTokenizer, AutoModelForTokenClassification
model_name = 'dbmdz/bert-large-cased-finetuned-conll03-english'
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForTokenClassification.from_pretrained(model_name)
tokenizer.save_pretrained('./models/bert-ner')
model.save_pretrained('./models/bert-ner')
print('Models downloaded successfully')
"
```

### 4. Configuration
```bash
# Copy and customize configuration
cp config.yaml config_local.yaml
# Edit config_local.yaml as needed
```

## Security Considerations for UBS

1. **Data Privacy**: All processing happens locally, no external API calls
2. **Model Security**: Use approved models only, verify checksums
3. **Logging**: Configure audit logging as per UBS requirements
4. **Access Control**: Implement proper authentication for API endpoints
5. **Encryption**: Enable result encryption if required

## Performance Optimization

1. **GPU Support**: Add `torch-gpu` if CUDA available
2. **Model Caching**: Enable model caching to reduce load times
3. **Batch Processing**: Configure batch sizes based on available memory
4. **Parallel Processing**: Adjust worker count based on CPU cores

## Monitoring and Maintenance

1. **Health Checks**: Use provided health check endpoints
2. **Performance Metrics**: Monitor processing times and accuracy
3. **Model Updates**: Schedule periodic model updates
4. **Log Rotation**: Configure log rotation to manage disk space

## Troubleshooting

### Common Issues:
1. **Memory Errors**: Reduce batch size or model complexity
2. **Model Loading**: Verify model files are in correct directory
3. **spaCy Issues**: Ensure language model is properly installed
4. **Performance**: Check system resources and optimize configuration

## Testing

```bash
# Run unit tests
pytest tests/

# Run integration tests
python -m pytest tests/integration/

# Performance testing
python scripts/performance_test.py
```

## API Usage

```python
# Basic usage example
from pii_pipeline import EnsemblePIIAnalyzer

analyzer = EnsemblePIIAnalyzer("ensemble", config)
result = analyzer.analyze(email_text)

print(f"Found {len(result.entities)} PII entities")
print(f"Masked text: {result.masked_text}")
```
